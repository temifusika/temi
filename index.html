How I work

Brief AI
like a director.

I write the brief and the rules; AI build agents write code under my direction; tests and a person decide what ships. Accounts, payments and production keys stay with me.

  1. Write the briefScope, acceptance criteria and the rules the system must never break.
  2. Plan firstDecisions recorded as notes that can be reversed.
  3. Tests decideUnit, database, isolation and layout tests gate every merge.
  4. Ship and watchDeploy, smoke-check production, watch the errors.
  5. Write it downRunbooks, handovers and an operating bible per business.
