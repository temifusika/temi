    How I work

    AI agents as a delivery team

    I write the brief and the rules; AI build agents write code under my direction; tests and a person decide what ships. Accounts, payments and production keys stay with me.

    1. I write the briefScope, acceptance criteria and the rules the system must never break.
    2. An agent plansPlan first, decisions recorded as notes I can reverse.
    3. Tests decideUnit, database, isolation and layout tests gate every merge.
    4. Ship and watchDeploy, smoke-check production, and watch Sentry.
    5. Write it downHandovers, runbooks and an operating bible for each business.
    AI proposes, people decideAI can read a bill and suggest values. It cannot write to the database. A person confirms; a second person checks.
    Live data changes, safelyA read-only check first, a dry run, a backup and a rollback file, and the database always updated before the code that uses it.
    No secrets in the openKeys live only in platform settings, and Google Cloud is reached without stored keys at all.
    Honest by defaultNo time promises, no invented numbers, and no claim the system can’t back up.
